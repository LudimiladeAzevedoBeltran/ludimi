PCA e Clusters: uma introdução prática

2026-08-01

Análise de Componentes Principais (PCA) é uma técnica para reduzir a dimensionalidade dos dados, preservando a maior parte da variância. Ela é muito usada antes de técnicas de agrupamento (clustering) para melhorar a visualização e o desempenho.

O que é PCA?

O PCA transforma as variáveis originais em novas combinações lineares chamadas de componentes principais, ordenadas pela quantidade de variância que explicam.

Agrupamento com K-Means

Com os componentes principais, aplicamos o K-Means para separar os dados em grupos com características semelhantes, facilitando a interpretação dos resultados.

from sklearn.decomposition import PCA
from sklearn.cluster import KMeans

X_pca = PCA(n_components=2).fit_transform(X)
clusters = KMeans(n_clusters=4).fit_predict(X_pca)
