Sobre este guia

Um bom gráfico transforma uma tabela em entendimento — é a alma da divulgação científica. Neste guia você aprende a construir visualizações com matplotlib (o básico) e seaborn (os tipos mais sofisticados), com códigos prontos para adaptar aos seus dados.

Imports que usamos sempre
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

np.random.seed(42)   # para dados aleatórios reproduzíveis

O seed(42) fixa o gerador de aleatórios: cada vez que rodar, sai o mesmo "aleatório" — útil para exemplos didáticos. (42 é uma referência a "O Guia do Mochileiro das Galáxias"!)

Seção 1 — Elementos básicos

1.1 Pontos (dispersão)

PYTHON — scatter
x = np.linspace(0, 10, 50)
y = np.random.rand(50)   # 50 valores aleatórios

plt.figure()
plt.scatter(x, y)        # gráfico de dispersão
plt.title("Dispersão simples")
plt.show()

1.2 Linhas

PYTHON — plot de linha
x = np.linspace(0, 10, 200)

plt.figure()
plt.plot(x, np.sin(x))   # gráfico de linha
plt.title("Linha simples")
plt.show()

1.3 Várias séries no mesmo gráfico

PYTHON — múltiplas linhas + legenda
x = np.linspace(0, 10, 200)

plt.figure()
plt.plot(x, np.sin(x), label="sin")
plt.plot(x, np.cos(x), label="cos")
plt.legend()       # mostra a legenda
plt.title("Múltiplas séries")
plt.show()
A anatomia de um gráfico matplotlib

Todo gráfico segue este esqueleto: plt.figure() cria a área → plt.plot/scatter desenha os dados → plt.title/label/legend embelezam → plt.show() exibe. Guarde essa ordem e você monta qualquer gráfico.

Seção 2 — Um gráfico completo

PYTHON — gráfico completo e publicável
x = np.linspace(0, 10, 200)

plt.figure()
plt.plot(x, np.sin(x), label="sin(x)")
plt.plot(x, np.cos(x), label="cos(x)")
plt.xlabel("x")          # label do eixo x
plt.ylabel("valor")       # label do eixo y
plt.title("Exemplo de gráfico completo")
plt.grid(True)            # grade
plt.legend()
plt.show()
Para artigos, capriche

Um gráfico para publicação precisa de: título ou legenda explicativa, eixos com unidade, legenda e grade quando ajudar a leitura. Cores com contraste e alpha (transparência) para sobreposição. É isso que separa um gráfico "de rascunho" de um gráfico científico.

Seção 3 — Banda de incerteza e anotações

3.1 Banda ao redor da média

PYTHON — linha com banda de incerteza
x = np.linspace(0, 10, 50)
media = np.sin(x)
ic = 0.3 + 0.2*np.random.rand(len(x))   # incerteza entre 0.3 e 0.5

plt.figure()
plt.plot(x, media, label="média")
plt.fill_between(x, media-ic, media+ic, alpha=0.3, label="incerteza")
plt.title("Linha com banda de incerteza")
plt.legend()
plt.show()

3.2 Linhas e faixas de referência

PYTHON — axhline, axvline, axvspan, text
plt.figure()
plt.plot(x, y)
plt.axhline(0, linestyle="--")          # linha horizontal em y=0
plt.axvline(0, linestyle="--")          # linha vertical em x=0
plt.axvspan(3, 4, alpha=0.2)               # faixa vertical destacada
plt.text(4.0, 1.1, "Região de interesse")
plt.show()
Para que serve

Banda de incerteza mostra a variabilidade de uma estimativa (muito comum em séries temporais e modelos). Linhas de referência marcam limiares (ex.: um limite de queimada, um valor crítico). Anotações chamam atenção para o que importa — é a base do storytelling nos dados.

Seção 4 — Tipos de gráficos (matplotlib)

4.1 Histograma e boxplot

PYTHON — distribuição de uma variável
amostra = np.random.normal(loc=50, scale=10, size=200)

plt.figure()
plt.hist(amostra, bins=20)      # histograma
plt.title("Histograma")
plt.show()

plt.figure()
plt.boxplot(amostra)            # boxplot
plt.title("Boxplot")
plt.show()

4.2 Barras categóricas

PYTHON — barplot
categorias = ["A", "B", "C", "D"]
valores = [12, 25, 18, 30]

plt.figure()
plt.bar(categorias, valores)
plt.title("Barplot")
plt.show()

4.3 Heatmap (matriz de correlação)

PYTHON — heatmap de correlação
df = pd.DataFrame(np.random.randn(100, 4), columns=["a", "b", "c", "d"])
corr = df.corr()

plt.figure()
plt.imshow(corr, cmap="coolwarm", vmin=-1, vmax=1)
plt.colorbar()
plt.xticks(range(4), df.columns)
plt.yticks(range(4), df.columns)
plt.title("Matriz de correlação")
plt.show()

Seção 5 — Gráficos estatísticos com seaborn

O seaborn é mais alto nível: com uma linha você já faz um gráfico bonito e estatisticamente correto. Ele conversa bem com o pandas — basta passar o DataFrame.

5.1 Boxplot e violin plot por categoria

PYTHON — seaborn boxplot e violin
dados = pd.DataFrame({
    "pais": np.repeat(["Brasil", "Colômbia", "Etiópia"], 50),
    "media": np.concatenate([np.random.normal(85, 5, 50),
                              np.random.normal(78, 4, 50),
                              np.random.normal(72, 6, 50)]),
})

sns.boxplot(data=dados, x="pais", y="media")
plt.title("Qualidade por país")
plt.show()

5.2 Pairplot (matriz de dispersão)

PYTHON — pairplot com seaborn
sns.pairplot(dados, hue="pais")
plt.show()
O pairplot gera uma grade com a relação entre todas as variáveis de uma vez — o resumo visual perfeito para explorar um conjunto de dados.

5.3 Heatmap e errobar

PYTHON — heatmap seaborn
sns.heatmap(df.corr(), annot=True, cmap="coolwarm", vmin=-1, vmax=1)
plt.show()
matplotlib vs seaborn

matplotlib é o "motor" de baixo nível — controle total. seaborn é uma camada acima — rápido e bonito para gráficos estatísticos. No dia a dia, você combina os dois: sns para criar e plt para ajustar (título, tamanho, salvar).

5.4 Salvar o gráfico

PYTHON — salvar em PNG
plt.figure(figsize=(8, 5))            # tamanho em polegadas
plt.plot(x, y)
plt.title("Minha figura")
plt.savefig("figura.png", dpi=300, bbox_inches="tight")   # alta resolução
plt.close()                           # libera a figura
dpi=300 dá a resolução de publicação; bbox_inches="tight" corta margens sobrando.
