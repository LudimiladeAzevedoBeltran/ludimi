Seção 1 — Listas

1.1 O código

PYTHON — listas
alunos = ["Ana", "Bruno", "Carla"]
notas = [8.5, 9.0, 7.5]

print(alunos[0])      # "Ana" (índice 0)
print(notas[1])       # 9.0

alunos.append("Diego")   # adiciona no fim
notas[0] = 9.5        # altera um elemento (listas são mutáveis)
print(len(alunos))    # 4 (tamanho)

1.2 A explicação

Uma lista guarda vários valores em ordem, e cada um é acessado por um índice (começando em 0). Listas são mutáveis: você pode adicionar, remover e alterar elementos. São a estrutura mais usada quando você vai trabalhar com dados.

Métodos úteis

sort()ordena
len(x)retorna o tamanho

Seção 2 — Tuplas

2.1 O código

PYTHON — tuplas
ponto = (3, 5)          # tupla com dois valores
print(ponto[0])         # 3

# ponto[0] = 4  # ERRO! tuplas são imutáveis

2.2 A explicação

Uma tupla é parecida com uma lista, mas imutável: depois de criada, não muda. É útil para dados que não devem ser alterados (como uma coordenada (x, y)). Usa () e é mais leve que a lista.

Seção 3 — Dicionários

3.1 O código

PYTHON — dicionários
aluno = {"nome": "Ana", "nota": 9.0, "curso": "Agronomia"}

print(aluno["nome"])    # "Ana"
print(aluno["nota"])    # 9.0

aluno["nota"] = 9.5   # atualiza um valor
aluno["cidade"] = "Jaboticabal"  # adiciona uma chave nova

print(aluno.keys())    # as chaves
print(aluno.values())  # os valores

3.2 A explicação

Um dicionário guarda pares chave → valor, em vez de posições numéricas. É como uma lista de contatos: você acessa pelo nome (chave), não pelo índice. É a estrutura perfeita para representar "registros" — e é exatamente assim que o pandas organiza colunas depois.

Quando usar cada uma
  • Lista — quando a ordem importa e você quer vários itens.
  • Tupla — quando os valores são fixos (ex.: coordenadas).
  • Dicionário — quando cada item tem um "nome" e um "valor".

Seção 4 — Percorrendo coleções

4.1 O código

PYTHON — laço for
alunos = ["Ana", "Bruno", "Carla"]

for nome in alunos:
    print(f"Aluno: {nome}")

# percorrendo com índice
for i, nome in enumerate(alunos):
    print(i, "-", nome)

4.2 A explicação

O laço for percorre cada elemento de uma coleção — a forma mais comum de processar dados. enumerate() te dá, além do valor, o índice. Isso é a base de tudo: é assim que você vai "varrer" uma lista de notas, uma planilha, uma coluna.

Desafio — registro de alunos

Crie uma estrutura que guarde dados de alunos e calcule a média das notas. Solução:

PYTHON — solução
alunos = [
    {"nome": "Ana",  "ra": 101, "nota": 8.5},
    {"nome": "Bruno", "ra": 102, "nota": 9.0},
    {"nome": "Carla", "ra": 103, "nota": 7.5},
]

soma = 0
for a in alunos:
    soma += a["nota"]

media = soma / len(alunos)
print(f"Média da turma: {media:.2f}")
