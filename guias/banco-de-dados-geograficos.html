Módulo 1 — O que é um dado geográfico

TEORIA

1.1 Explicação

Um dado geográfico é aquela informação que tem uma localização associada: um rio, uma cidade, um fragmento florestal. Ele combina duas partes inseparáveis:

As duas componentes de um dado geográfico
  • Geométrica (espacial) — a forma e posição no espaço: um ponto, uma linha, um polígono.
  • Convencional (descritiva/atributos) — as características: nome, população, uso do solo.

O grande desafio dos bancos de dados geográficos é armazenar e consultar essas duas partes de forma conjunta e eficiente.

1.2 Fundamentação teórica — os universos

A literatura (camada de Silva, 2002) organiza a modelagem geográfica em três universos:

UniversoO que faz
Ontológicocomo o mundo real é percebido: o que existe (rio, cidade, floresta).
Formala teoria da medida: como quantificar e representar (coordenadas, escala).
Estruturala estrutura de dados: matricial ou vetorial.

Módulo 2 — Representação: matricial e vetorial

TEORIA

No universo estrutural, existem dois grandes modelos de representação espacial.

1. Matricial (raster / tesselação)
O espaço é dividido em uma grade de células, cada uma com um valor. É a base de imagens de satélite e dos dados de sensoriamento remoto. Cada pixel representa a média de uma área. Uso: tipos de solo, uso da terra, modelos de elevação.
2. Vetorial
O espaço é representado por objetos geométricos: pontos, linhas e polígonos, definidos por coordenadas. Uso: limites de municípios, ruas, cadastro de imóveis. Permite precisão e consultas topológicas (o que está dentro, o que faz vizinhança).

Módulo 3 — Arquitetura de bancos de dados geográficos

PRÁTICA

3.1 Arquitetura Dual

A arquitetura dual separa os dois tipos de dado: os atributos ficam em um banco relacional (SGBD), e a geometria fica em estruturas internas da ferramenta SIG. Um identificador comum (geo-id) conecta as duas partes.

Vantagem e desvantagem

Vantagem: flexibilidade — você escolhe o SGBD relacional que preferir. Desvantagem: para responder uma consulta simples, dois processos são acionados (espacial + descritivo), e a integridade pode ficar comprometida se a conexão falhar.

Dois exemplos clássicos de arquitetura dual: Arc-Info (ESRI) e o SPRING (INPE) — este último usa o modelo relacional para dados não espaciais e o modelo orientado a objetos para os geográficos, além da linguagem LEGAL para manipulação espacial.

3.2 A alternativa: SGBD espacial

Com o tempo, os próprios bancos passaram a suportar tipos espaciais nativamente (ex.: PostGIS, extensão do PostgreSQL). Nessa abordagem, geometria e atributos ficam no mesmo banco, o que simplifica as consultas e garante integridade — é a opção usada hoje pela maioria dos sistemas.

Módulo 4 — Consultas espaciais com SQL/PostGIS

CÓDIGO

4.1 Explicação

Programas como PostGIS adicionam aos bancos relacionais a capacidade de armazenar geometria (GEOMETRY, GEOGRAPHY) e de responder a consultas espaciais: "o que está dentro desta área?", "o que está próximo?", "o que se sobrepõe?".

SQL — consultas espaciais com PostGIS
CREATE TABLE municipios (
    id SERIAL PRIMARY KEY,
    nome TEXT,
    geom GEOMETRY(GEOMETRY, 4326)   -- SRID 4326 = WGS84 (lat/lon)
);

SELECT ST_Area(geom) AS area, nome
FROM municipios;

-- o que está dentro de uma área de interesse
SELECT m.nome
FROM municipios m
WHERE ST_Within(m.geom, ST_GeomFromText('POLYGON((...))', 4326));
ST_Within, ST_Area, ST_Intersects são funções espaciais. O SRID informa o sistema de coordenadas usado (WGS84 é o padrão global).

Módulo 5 — Python na prática: geopandas

CÓDIGO

O geopandas é a sua ferramenta para trabalhar com dados geoespaciais em Python: une a manipulação do pandas com a capacidade de lidar com geometrias.

5.1 Lendo e visualizando um arquivo geoespacial

PYTHON — lendo um shapefile com geopandas
import geopandas as gpd

gdf = gpd.read_file("municipios.shp")

print(gdf.head())          # dados descritivos
print(gdf.geometry)        # geometrias (vetoriais)
print(gdf.crs)             # sistema de coordenadas (CRS)

5.2 Consultas espaciais em Python

PYTHON — o que está dentro de um polígono
import geopandas as gpd
from shapely.geometry import Point

pontos = gpd.GeoDataFrame(
    {"nome": ["A", "B"]},
    geometry=[Point(-48, -15), Point(-47, -12)]
)

# área de referência (um polígono)
area = gpd.GeoDataFrame(geometry=[Point(-48, -15).buffer(0.5)])

dentro = pontos[pontos.geometry.within(area.geometry.iloc[0])]
print(dentro)
within, intersects e distance são as operações espaciais que você mais usará. Elas respondem "o que está dentro, perto ou encima de quê".

5.3 Visualizando no mapa

PYTHON — plotando geometrias
import geopandas as gpd

gdf = gpd.read_file("municipios.shp")
gdf.plot(column="populacao", cmap="Greens", legend=True)
Um único método (plot) gera um mapa temático (coroplético) — o mesmo conceito que você viu em Data Storytelling, aplicado a dados geográficos.

Consideração final

Bancos de dados geográficos são a espinha dorsal das geotecnologias. Entender como o dado espacial é representado (matricial ou vetorial) e como armazená-lo e consultá-lo — agora com ferramentas como PostGIS e geopandas — é o que permite transformar mapas em decisões e em pesquisa científica.
