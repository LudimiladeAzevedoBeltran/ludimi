Seção 1 — Tendência central

1.1 O código

PYTHON — média, mediana
dados = [45, 47, 49, 50, 52, 55, 120]   # cuidado: um valor atípico (120)

print("Média:", np.mean(dados))      # 59.7 (puxada pelo 120)
print("Mediana:", np.median(dados))   # 50 (robusta)
print("Desvio padrão:", np.std(dados))

1.2 A explicação

A média é a soma dividida pela quantidade, mas é sensível a valores atípicos (outliers). A mediana é o valor do meio e não muda com extremos. Esse será o exemplo clássico: se um valor destoa, a média "mentiu" e a mediana não.

Regra prática

Se a média e a mediana são bem diferentes, é sinal de que há outliers ou distribuição assimétrica. Nesse caso, reporte a mediana como medida mais honesta.

Seção 2 — Variabilidade

2.1 O código

PYTHON — variância e desvio padrão
serie_a = [49, 50, 51, 50, 49]      # pouco variável
serie_b = [30, 60, 45, 50, 70]      # muito variável

print("A", np.std(serie_a))   # ~0.8
print("B", np.std(serie_b))   # ~14.6

2.2 A explicação

A variância mede o quanto os valores se afastam da média (em unidades ao quadrado). O desvio padrão é a raiz quadrada da variância — volta para a mesma escala dos dados, por isso é o mais usado. Duas séries podem ter a mesma média e variabilidades totalmente diferentes.

Coeficiente de variação (CV)

cv = (desvio / média) * 100 expressa a variabilidade em porcentagem, permitindo comparar séries de unidades diferentes. É muito usado em ciências agrárias e experimentais.

Seção 3 — Padronização (z-score)

3.1 O código

PYTHON — padronizando dados
serie = np.array([45, 47, 49, 50, 52, 55])

media = np.mean(serie)
desvio = np.std(serie)

z = (serie - media) / desvio
print(z)   # valores padronizados

# pronto, com scipy
z2 = stats.zscore(serie)
print(z2)

3.2 A explicação

A padronização transforma os dados para ter média 0 e desvio 1. O z-score diz "quantos desvios-padrão um valor está da média". Isso permite comparar variáveis em escalas diferentes — essencial antes de modelos e de juntar dados heterogêneos.

Por que padronizar

Imagine temperatura (20–30°C) e umidade (60–90%). Em escala bruta, a umidade "domina" qualquer cálculo. Ao padronizar, ambas ficam comparáveis. É um passo obrigatório em clustering e PCA.

Seção 4 — Distribuição normal

4.1 O código — calculando probabilidades

PYTHON — probabilidades com scipy
import scipy.stats as sts

media = 49    # média (ex.: peso de pãezinhos, em g)
dp = 2.8      # desvio padrão

# P(peso atÉ 50g)
p50 = sts.norm.cdf(50, media, dp)
print("até 50g:", p50)

# P(entre 50 e 52g)
pinf = sts.norm.cdf(50, media, dp)
psup = sts.norm.cdf(52, media, dp)
print("entre 50 e 52:", psup - pinf)

# P(igual ou maior que 55g)
p55 = 1 - sts.norm.cdf(55, media, dp)
print(">= 55g:", p55)

4.2 A explicação

A distribuição normal (curva em sino) é o modelo mais usado. Com scipy.stats.norm você calcula probabilidades: cdf responde "qual a chance de ser ≤ aquele valor?". A área total sob a curva é 1 (100%), então 1 - cdf dá a chance de ser maior que um valor.

Interpretação prática

Se a média é 49g e o desvio 2.8g, cerca de 68% dos valores ficam entre 49 ± 2.8 e 95% entre 49 ± 5.6. É a famosa "regra empírica" que você vai usar para interpretar qualquer coisa que se distribua normalmente.

Seção 5 — Explorando com seaborn

5.1 Distribuição e boxplot

PYTHON — visualizando a distribuição
dados = np.random.normal(loc=49, scale=2.8, size=200)

sns.histplot(dados, kde=True)       # histograma + curva de densidade
plt.title("Distribuição dos dados")
plt.show()

sns.boxplot(dados)                     # boxplot: mediana, quartis, outliers
plt.show()
O boxplot mostra a mediana, os quartis e marca os outliers como pontos isolados — o jeito mais rápido de "ver" a distribuição e detectar valores estranhos.
