Módulo 1 — O que é Machine Learning

TEORIA

1.1 Explicação

Machine Learning é um campo da Inteligência Artificial que desenvolve algoritmos capazes de aprender com dados e melhorar com a experiência, sem serem explicitamente programados para cada caso.

A ideia central

No programação tradicional, você escreve as regras. No ML, você dá exemplos ao algoritmo e ele descobre as regras sozinho. Em vez de programar "se o e-mail tem X, é spam", você mostra milhares de e-mails (spam e não-spam) e o modelo aprende a distinguir.

1.2 O processo de ML

1
Definir o problema O que você quer prever ou agrupar?
2
Preparar os dados Limpar, tratar valores ausentes, escolher as variáveis (features).
3
Treinar o modelo Uma parte dos dados ensina o algoritmo.
4
Avaliar Testar em dados não vistos para medir a generalização.
5
Prever e monitorar Usar em produção e acompanhar se continua funcionando.
Aplicações que você conhece

Diagnóstico médico, previsão de demanda, detecção de fraude, recomendação, e — na sua área — modelos preditivos de produtividade, classificação de queimadas e análise de clusters. É exatamente o que você trabalha nos seus artigos.

Módulo 2 — Tipos de aprendizado

TEORIA

O ML se divide em dois grandes grupos, conforme os dados disponíveis.

1. Aprendizado supervisionado
Você tem rótulos (a resposta certa) e ensina o modelo. Subdivide-se em: classificação (categoria — ex.: é queimada ou não) e regressão (valor contínuo — ex.: área queimada).
2. Aprendizado não supervisionado
Você não tem rótulos; o algoritmo descobre padrões por conta própria. O principal exemplo é o clustering (agrupamento) — como o K-Means que você usa na análise de clusters.
3. Aprendizado por reforço
O agente aprende por tentativa e recompensa (como ensinar um robô a andar). Menos comum em análise de dados, mas parte do campo.

Módulo 3 — Overfitting, underfitting e validação

PRÁTICA

3.1 Os conceitos — explicação

As duas armadilhas
  • Underfitting — o modelo é simples demais e não aprende o padrão (desempenho ruim até no treino).
  • Overfitting — o modelo decorou os dados de treino e não generaliza (arrasa no treino, falha em dados novos).

O objetivo é encontrar o equilíbrio: um modelo que aprenda o padrão, mas não o "ruído". A principal ferramenta para isso é a validação cruzada.

3.2 O código

PYTHON — validação cruzada
from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import cross_val_score

X, y = load_iris(return_X_y=True)
modelo = DecisionTreeClassifier(max_depth=3)

notas = cross_val_score(modelo, X, y, cv=5)
print(notas)                       # 5 notas, uma por dobra
print("média:", notas.mean())
O que a validação cruzada faz

Ela divide os dados em 5 partes (cv=5), treina em 4 e testa em 1, repetindo. Isso dá uma medida mais honesta de como o modelo se comporta em dados nunca vistos — bem melhor do que testar nos próprios dados de treino.

Módulo 4 — Algoritmos em Python

CÓDIGO

4.1 Classificação (supervisionado)

PYTHON — árvore de decisão
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score

X, y = load_iris(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=42)

modelo = DecisionTreeClassifier(max_depth=3)
modelo.fit(X_tr, y_tr)
pred = modelo.predict(X_te)

print("Acurácia:", accuracy_score(y_te, pred))
Árvores de decisão são interpretáveis: você consegue ver as regras que o modelo usou — ótimo para explicar resultados em artigos.

4.2 Clustering (não supervisionado)

PYTHON — K-Means
from sklearn.cluster import KMeans
import numpy as np

X = np.random.rand(60, 2)          # dados de exemplo
modelo = KMeans(n_clusters=3, n_init=10, random_state=0)
modelo.fit(X)

print(modelo.labels_)            # o grupo de cada ponto
print(modelo.cluster_centers_)   # o centro de cada grupo
É o mesmo princípio dos seus estudos de cluster — os dados se agrupam naturalmente, e você interpreta cada grupo com o conhecimento do domínio.

Módulo 5 — Deep Learning

PRÁTICA

5.1 Explicação

O Deep Learning é uma subárea do ML baseada em redes neurais artificiais com muitas camadas (por isso "deep"). Elas se destacam quando há muito dado e problemas complexos, como imagens, áudio e texto.

Redes neurais artificiais (RNAs)

Inspiradas no cérebro, as RNAs têm neurônios organizados em camadas (entrada, ocultas, saída). Cada conexão tem um peso, ajustado durante o treino por um processo chamado backpropagation — que corrige os pesos a partir do erro. Funções de ativação (como ReLU e sigmoide) decidem o que cada neurônio "dispara".

CNNs — Redes Neurais Convolucionais
Especializadas em imagens. Detectam padrões visuais (bordas, formas, texturas) e são a base do reconhecimento de imagens — muito relevantes para sensoriamento remoto e análise de queimadas.
RNNs / LSTMs — Redes Neurais Recorrentes
Especializadas em sequências: texto, áudio e séries temporais. As LSTM (Long Short-Term Memory) memorizam relações de longo prazo — úteis para séries climáticas e temporais.
Quando usar deep learning
  • Você tem muitos dados (dezenas de milhares de exemplos).
  • O problema é complexo (imagens, texto, áudio).
  • Métodos clássicos (regressão, árvores) não funcionam bem.

Caso contrário, os modelos clássicos de ML costumam ser mais simples, interpretáveis e suficientes — e é com eles que você provavelmente trabalhará na pesquisa.

5.2 Primeiro contato com uma rede neural

PYTHON — uma rede simples com Keras
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense

modelo = Sequential([
    Dense(8, activation="relu", input_shape=(4,)),
    Dense(3, activation="softmax"),
])
modelo.compile(optimizer="adam", loss="categorical_crossentropy", metrics=["accuracy"])
print(modelo.summary())
Uma rede com uma camada oculta (8 neurônios, ReLU) e uma de saída (3 classes, softmax). O summary() mostra a arquitetura — o "esqueleto" da rede que você construiu.

Checklist

  • Sei a diferença entre supervised e unsupervised learning
  • Entendo overfitting e underfitting
  • Usei validação cruzada
  • Rodei uma árvore de decisão e um K-Means
  • Sei o que são CNNs e RNNs
Consideração final

Machine Learning é uma ferramenta poderosa, mas não é a resposta para tudo. O que diferencia uma boa análise é o problema bem definido, os dados de qualidade e a validação honesta — não o algoritmo mais sofisticado. Comece com modelos simples e interpretáveis; só avance para o deep learning se a complexidade exigir.
