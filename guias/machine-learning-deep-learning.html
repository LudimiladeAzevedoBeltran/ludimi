O que é Machine Learning

Teoria

1.1 A ideia central

Machine Learning é um campo da Inteligência Artificial que desenvolve algoritmos capazes de aprender com dados e melhorar com a experiência, sem serem explicitamente programados para cada caso.

✓
A ideia central. No programação tradicional, você escreve as regras. No ML, você dá exemplos ao algoritmo e ele descobre as regras sozinho. Em vez de programar "se o e-mail tem X, é spam", você mostra milhares de e-mails (spam e não-spam) e o modelo aprende a distinguir.

1.2 O processo de ML — o fluxo

Problema
Definir a pergunta e o que prever
›
Dados
Limpar e escolher as variáveis
›
Treino
O algoritmo aprende o padrão
›

›
Previsão
Uso real + monitoramento contínuo
O ciclo do ML: do problema à previsão — e de volta, sempre que os dados mudam.
◆
Aplicações que você conhece. Diagnóstico médico, previsão de demanda, detecção de fraude — e na sua área, modelos preditivos de produtividade, classificação de queimadas e análise de clusters. É exatamente o que você trabalha nos artigos.

Tipos de aprendizado

Teoria

O ML se divide em dois grandes grupos, conforme os dados disponíveis.

1. Aprendizado supervisionado
Você tem rótulos (a resposta certa) e ensina o modelo. Subdivide-se em: classificação (categoria — ex.: é queimada ou não) e regressão (valor contínuo — ex.: área queimada).
2. Aprendizado não supervisionado
Você não tem rótulos; o algoritmo descobre padrões por conta própria. O principal exemplo é o clustering (agrupamento) — como o K-Means que você usa na análise de clusters.
3. Aprendizado por reforço
O agente aprende por tentativa e recompensa (como ensinar um robô a andar). Menos comum em análise de dados, mas parte do campo.
ℹ
Como escolher. Seus dados têm rótulos? Se são categorias → classificação; se são valores contínuos → regressão; se não têm rótulos → clustering.

Overfitting, underfitting e validação

Prática
◈
As duas armadilhas.
  • Underfitting — o modelo é simples demais e não aprende o padrão (desempenho ruim até no treino).
  • Overfitting — o modelo decorou os dados de treino e não generaliza (arrasa no treino, falha em dados novos).

O objetivo é encontrar o equilíbrio: um modelo que aprenda o padrão, mas não o "ruído". A principal ferramenta para isso é a validação cruzada.

PYTHON — validação cruzada
from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import cross_val_score

X, y = load_iris(return_X_y=True)
modelo = DecisionTreeClassifier(max_depth=3)

notas = cross_val_score(modelo, X, y, cv=5)
print(notas)                       # 5 notas, uma por dobra
print("média:", notas.mean())
Ela divide os dados em cv=5 partes, treina em 4 e testa em 1, repetindo — mede a generalização de forma honesta.

Algoritmos em Python

Código

4.1 Classificação (supervisionado)

PYTHON — árvore de decisão
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score

X, y = load_iris(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=42)

modelo = DecisionTreeClassifier(max_depth=3)
modelo.fit(X_tr, y_tr)
pred = modelo.predict(X_te)

print("Acurácia:", accuracy_score(y_te, pred))
Árvores são interpretáveis: você vê as regras que o modelo usou — ótimo para explicar em artigos.

Uma árvore de decisão funciona exatamente como a ramificação de um fluxograma: a cada nó, o modelo faz uma pergunta e segue por um dos ramos, até chegar a uma folha (a classe final).

Raiz
Pétala larga > 0,8?
Sim
Pétala comprida → classe versicolor
Não
Pétala larga > 0,2?
Sim
Classe setosa
Não
Classe virginica
Cada nó é uma pergunta; cada folha é uma resposta. É assim que a árvore decide.

4.2 Clustering (não supervisionado)

PYTHON — K-Means
from sklearn.cluster import KMeans
import numpy as np

X = np.random.rand(60, 2)          # dados de exemplo
modelo = KMeans(n_clusters=3, n_init=10, random_state=0)
modelo.fit(X)

print(modelo.labels_)            # o grupo de cada ponto
print(modelo.cluster_centers_)   # o centro de cada grupo
O mesmo princípio dos seus estudos de cluster — os dados se agrupam naturalmente, e você interpreta cada grupo com o conhecimento do domínio.

Deep Learning

Prática

O Deep Learning é uma subárea do ML baseada em redes neurais artificiais com muitas camadas (por isso "deep"). Elas se destacam quando há muito dado e problemas complexos, como imagens, áudio e texto.

✓
Redes neurais artificiais (RNAs). Inspiradas no cérebro, têm neurônios em camadas (entrada, ocultas, saída). Cada conexão tem um peso, ajustado no treino pelo backpropagation — que corrige os pesos a partir do erro. Funções de ativação (ReLU, sigmoide) decidem o que cada neurônio "dispara".
CNNs — Redes Neurais Convolucionais
Especializadas em imagens. Detectam padrões visuais (bordas, formas, texturas) e são a base do reconhecimento de imagens — muito relevantes para sensoriamento remoto e análise de queimadas.
RNNs / LSTMs — Redes Neurais Recorrentes
Especializadas em sequências: texto, áudio e séries temporais. As LSTM memorizam relações de longo prazo — úteis para séries climáticas e temporais.
◆
Quando usar deep learning. Você tem muitos dados? O problema é complexo (imagens, texto)? Métodos clássicos não funcionam? Caso contrário, os modelos clássicos de ML costumam ser mais simples, interpretáveis e suficientes — e é com eles que você provavelmente trabalhará na pesquisa.

5.1 Primeiro contato com uma rede neural

PYTHON — uma rede simples com Keras
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense

modelo = Sequential([
    Dense(8, activation="relu", input_shape=(4,)),
    Dense(3, activation="softmax"),
])
modelo.compile(optimizer="adam", loss="categorical_crossentropy", metrics=["accuracy"])
print(modelo.summary())
Uma camada oculta (8 neurônios, ReLU) + uma de saída (3 classes, softmax). O summary() mostra a arquitetura — o "esqueleto" da rede.

Checklist

  • Sei a diferença entre supervised e unsupervised learning
  • Entendo overfitting e underfitting
  • Usei validação cruzada
  • Rodei uma árvore de decisão e um K-Means

✓
Consideração final. Machine Learning é poderosa, mas não é a resposta para tudo. O que diferencia uma boa análise é o problema bem definido, os dados de qualidade e a validação honesta — não o algoritmo mais sofisticado. Comece com modelos simples e interpretáveis.
