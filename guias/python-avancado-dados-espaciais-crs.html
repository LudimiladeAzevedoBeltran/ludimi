Seção 1 — Sistemas de referência de coordenadas (CRS)

1.1 Explicação

Até aqui usávamos coordenadas (x, y) sem perguntar o que elas significam. Mas a Terra é um globo, e para representá-la no plano (um mapa) precisamos de um sistema de referência — o CRS (Coordinate Reference System).

Os dois tipos de coordenadas
TipoUsaEPSG comum
Geográficasgraus de longitude/latitude.EPSG:4326 (WGS84)
Projetadasmetros (planas).EPSG:31982 (BR)

EPSG:4326 (WGS84) é o mais comum (GPS, mapas). EPSG:31982 é uma projeção em metros usada no Brasil. Usar coordenadas geográficas para medir distâncias dá resultado errado — por isso reprojetamos.

1.2 O código

PYTHON — inspecionando o CRS
import geodatasets as gds

usa = gpd.read_file(gds.get_path('geoda.natregimes'))
print(usa.crs)          # o sistema de referência
print(usa.crs.name)     # nome do CRS
Por que se importar com o CRS

Se você sobrepõe duas camadas com CRS diferentes sem reprojetar, elas ficam "descascadas" — cada uma num sistema, e as formas não se alinham. Verificar e alinhar o CRS é o passo nº 1 de qualquer análise espacial séria.

Seção 2 — Reprojeção

2.1 O código

PYTHON — to_crs
f, ax = plt.subplots(figsize=(5, 5))
usa.plot(ax=ax)
ax.set_title(fr'USA - CRS: {usa.crs.name}', fontsize=12)
ax.axis('off')
plt.show()

# reprojetando para a projeção Albers (em metros)
usa_albers = usa.to_crs('ESRI:102003')
f, ax = plt.subplots(figsize=(5, 5))
usa_albers.plot(ax=ax)
ax.set_title(fr'USA - CRS: {usa_albers.crs.name}', fontsize=12)
ax.axis('off')
plt.show()

2.2 A explicação

to_crs(codigo) converte o GeoDataFrame para outro sistema de referência. É o que você usa para: - unificar camadas de fontes diferentes; - passar de graus (EPSG:4326) para metros e poder calcular áreas e distâncias corretamente.

Criar um GeoDataFrame já reprojetado
campo = gpd.GeoDataFrame(geometry=[sua_geometria],
                         crs='EPSG:4326').to_crs('EPSG:31982')

Repare: você informa o CRS de origem (crs=) e logo converte com to_crs. Esse padrão é muito usado para dados de GPS (4326) → projeção local em metros.

Seção 3 — Joins espaciais

3.1 Explicação

Um spatial join combina duas camadas pela localização: "para cada ponto, qual é o polígono que o contém?". É a operação que conecta dados de pontos a dados de área.

PYTHON — sjoin
import geopandas as gpd
from shapely.geometry import Point, Polygon

# camada de áreas (ex.: municípios)
areas = gpd.GeoDataFrame(
    {"municipio": ["A", "B"]},
    geometry=[Polygon([(0,0),(2,0),(2,2),(0,2)]),
              Polygon([(2,0),(4,0),(4,2),(2,2)])],
)

# camada de pontos (ex.: estações)
pontos = gpd.GeoDataFrame(
    {"estacao": ["E1", "E2", "E3"]},
    geometry=[Point(1,1), Point(3,1), Point(5,5)],
)

unido = gpd.sjoin(pontos, areas, how="left", predicate="within")
print(unido)
predicate="within" diz "para cada ponto, qual polígono o contém". O resultado adiciona a coluna do município a cada estação — exatamente o que se faz em estudos de campo.

3.2 Aplicação

Essa operação responde perguntas práticas: "em qual bioma está cada ponto de queimada?", "a qual setor censitário pertence cada imóvel?", "quais amostras de solo caem em cada tipo de relevo?". É o coração da análise espacial aplicada.

Seção 4 — Mapas interativos com folium

4.1 Explicação

O folium gera mapas interativos (que podem ser clicados, com zoom) e salva em HTML — perfeito para apresentar e publicar na web, direto no seu blog.

PYTHON — mapa interativo com marcadores
import folium

# centro do mapa e zoom
m = folium.Map(location=[-15.8, -48.5], zoom_start=10)

folium.Marker([-15.8, -48.5], popup="Ponto 1").add_to(m)
folium.Marker([-16.1, -48.2], popup="Ponto 2").add_to(m)

m.save("meu_mapa.html")     # gera um arquivo que abre no navegador

4.2 Mapas interativos a partir de um GeoDataFrame

PYTHON — pontos de um GeoDataFrame no folium
import folium
import geopandas as gpd
from shapely.geometry import Point

gdf = gpd.GeoDataFrame(
    {"nome": ["A", "B"]},
    geometry=[Point(-48.5, -15.8), Point(-48.2, -16.1)],
)

m = folium.Map(location=[-15.9, -48.4], zoom_start=9)
for _, linha in gdf.iterrows():
    folium.Marker(
        [linha.geometry.y, linha.geometry.x],
        popup=linha["nome"],
    ).add_to(m)

Seção 5 — Um fluxo de análise completo

Vamos juntar tudo em um fluxo realista e reprodutível:

PYTHON — análise espacial completa
import geopandas as gpd
import folium

# 1) carregar e conferir o CRS
areas = gpd.read_file("meus_municipios.shp")            # seu arquivo
print(areas.crs)

# 2) reprojetar para metros (se precisar calcular área)
areas_m = areas.to_crs('EPSG:31982')
areas_m["area_km2"] = areas_m.geometry.area / 1_000_000
print(areas_m[["nome", "area_km2"]])

# 3) associar pontos às áreas (spatial join)
pontos = gpd.read_file("meus_pontos.shp")
unido = gpd.sjoin(pontos, areas, predicate="within")

# 4) mapa interativo dos resultados
m = folium.Map(location=[areas.total_bounds[1], areas.total_bounds[0]], zoom_start=8)
for _, p in unido.iterrows():
    folium.Marker([p.geometry.y, p.geometry.x],
                  popup=f"{p['nome']} - {p.get('municipio', '')}").add_to(m)
m
O fluxo padrão da análise espacial

1) Carregar e checar CRS → 2) reprojetar se preciso → 3) espacial join para associar → 4) visualizar/mapas interativos. Memorize essa sequência — ela resolve a maioria das análises espaciais que você fará na pesquisa.

Checklist

  • Sei a diferença entre coordenadas geográficas e projetadas
  • Verifico o CRS e reprojeto com to_crs
  • Faço spatial join para associar pontos a áreas
  • Crio um mapa interativo com folium
  • Montar um fluxo completo de análise espacial
