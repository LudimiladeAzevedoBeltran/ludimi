Seção 1 — O que é regressão linear

1.1 A ideia

A regressão linear ajusta uma reta que melhor se encaixa nos pontos, minimizando a distância entre a reta e os dados (método dos mínimos quadrados — "Ordinary Least Squares" ou OLS).

A equação

y = a + b·x

  • a (intercepto) — valor de y quando x = 0.
  • b (coeficiente angular) — quanto y muda a cada unidade de x.

1.2 Primeiro olhar

PYTHON — um exemplo simples
xobs = [1, 3, 5, 2]
yobs = [1.2, 2.5, 4, 1.7]

sns.scatterplot(x=xobs, y=yobs)   # dispersão: já dá pra ver a tendência!
plt.show()

Seção 2 — Regressão linear simples

PYTHON — ajustando o modelo com statsmodels
xobs = [1, 3, 5, 2]
yobs = [1.2, 2.5, 4, 1.7]

xobsC = sm.add_constant(xobs)          # adiciona o intercepto (constante)
resultado = sm.OLS(yobs, xobsC).fit()  # OLS = mínimos quadrados ordinários

print(resultado.summary())            # tabela de interpretação completa
Por que add_constant?

Regressão precisa do intercepto (a). O sm.add_constant adiciona uma coluna de 1s que representa essa constante. Sem ela, a reta é forçada a passar pela origem — quase sempre errado.

Seção 3 — Interpretando o resultado

No summary(), as três coisas mais importantes são:

ValorO que significa
Coeficientes (coef)o a (const) e o b (inclinação) da reta.
p-valor (P>|t|)se < 0.05, a relação é estatisticamente significativa.
R² (R-squared)a proporção da variação de y explicada pelo modelo (0 a 1).
Correlação ≠ causalidade

Um R² alto e um p-valor significativo mostram que a relação existe, mas não provam causa. Duas variáveis podem andar juntas por uma terceira causa. Tenha isso em mente ao escrever sua pesquisa — é o erro conceitual mais comum.

3.1 Visualizando a reta

PYTHON — lmplot (reta ajustada)
df = pd.DataFrame({"x": xobs, "y": yobs})
sns.lmplot(x="x", y="y", data=df)   # dispersão + reta ajustada
plt.xticks([0, 1, 2, 3, 4, 5])
plt.show()
O lmplot desenha os pontos, a reta e ainda a faixa de confiança (região sombreada) ao redor — perfeito para apresentar resultados.

Seção 4 — Regressão linear múltipla

4.1 Quando usar

Quando y depende de mais de uma variável, usamos a regressão múltipla: cada variável ganha seu próprio coeficiente, e o modelo estima o efeito de cada uma controlada pelas demais.

PYTHON — regressão múltipla
import statsmodels.api as sm

# (exemplo conceitual) y = produtividade; x1, x2, x3 = variáveis explicativas
X = df[["x1", "x2", "x3"]]
y = df["y"]

Xc = sm.add_constant(X)
modelo = sm.OLS(y, Xc).fit()
print(modelo.summary())
Cuidado com multicolinearidade

Se duas variáveis explicativas são muito correlacionadas entre si, o modelo fica instável e os coeficientes perdem sentido. Sempre cheque a correlação entre as variáveis antes de ajustar.

Seção 5 — Validação e previsão

5.1 Analisando os resíduos

Os resíduos são a diferença entre o valor real e o previsto. Um bom modelo tem resíduos aleatórios (sem padrão). Analisá-los é essencial.

PYTHON — distribuição dos resíduos
import statsmodels.api as sm

residuos = resultado.resid
sm.qqplot(residuos, line="45")        # normalidade dos resíduos
plt.show()

sns.histplot(residuos, kde=True)     # se for um sino, ok!
plt.show()

5.2 Prevendo novos valores

PYTHON — previsão
novo_x = sm.add_constant([7, 9])    # novos valores de x
previsao = resultado.predict(novo_x)
print(previsao)
Recapitulando a validação
  • R² — quanto os dados são explicados.
  • p-valor — a relação é significativa?
  • Resíduos — têm padrão? São normais?

Um modelo só é confiável se as três coisas estão bem.

5.3 Checklist

  • Sei a equação y = a + b·x e o que é cada termo
  • Ajustei um OLS com statsmodels
  • Interpreto coeficientes, p-valor e R²
  • Fiz regressão múltipla e sei o risco de multicolinearidade
  • Analisei os resíduos e fiz uma previsão
