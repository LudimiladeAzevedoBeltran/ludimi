Seção 1 — Variáveis

1.1 O código

PYTHON — variáveis
nome = "Ludimila"
idade = 26
altura = 1.52
estudante = True

print(nome)
print(idade, altura, estudante)

1.2 A explicação

Uma variável é um "nome" que guarda um valor dentro da memória. No Python, você não precisa declarar o tipo — ele é inferido automaticamente pelo valor que você coloca. nome guarda um texto, idade um número inteiro, altura um decimal e estudante um valor lógico.

Regras de nome
  • Use letras, números e _, mas não comece com número.
  • Prefira nomes descritivos: idade_aluno é melhor que x.
  • Python é sensível a maiúsculas: idade e Idade são diferentes.
Experimente

Crie a sua própria variável (ex.: cidade = "Jaboticabal") e mostre com print.

Seção 2 — Tipos de dados

2.1 O código

PYTHON — tipos e o operador type()
inteiro = 42
decimal = 3.14
texto = "olá"
logico = True
nada = None

print(type(inteiro))   # int
print(type(decimal))   # float
print(type(texto))     # str
print(type(logico))    # bool
print(type(nada))      # NoneType

2.2 A explicação

Cada valor tem um tipo, e isso determina o que você pode fazer com ele. O operador type() revela o tipo — ferramenta essencial para entender o que está acontecendo.

TipoExemplosPara quê
int42, -3, 0números inteiros
float3.14, 1.65números decimais
str"olá", 'hello'texto
boolTrue, Falselógico (verdadeiro/falso)

Atenção

"10" (texto) e 10 (número) são coisas diferentes no Python. Somar texto com número dará erro. Sempre confira os tipos!

Seção 3 — Operadores

3.1 O código

PYTHON — operadores aritméticos, de comparação e lógicos
# Aritméticos
print(7 + 3)   # 10
print(7 - 3)   # 4
print(7 * 3)   # 21
print(7 / 2)   # 3.5 (divisão real)
print(7 // 2)  # 3 (divisão inteira)
print(7 % 2)   # 1 (resto)
print(7 ** 2)  # 49 (potência)

# Comparação (retorna bool)
print(5 > 3)   # True
print(5 == 5)  # True
print(5 != 3)  # True

# Lógicos
print(True and False)  # False
print(True or False)   # True
print(not True)          # False

3.2 A explicação

Os operadores aritméticos fazem matemática. Os de comparação devolvem True ou False. Os lógicos (and, or, not) combinam condições — a base de qualquer decisão no seu programa.

Destaque

== é igualdade (compara), enquanto = é atribuição (guarda um valor). É um erro muito comum confundir os dois!

Seção 4 — Entrada e saída

4.1 O código

PYTHON — input() e f-strings
nome = input("Qual seu nome? ")
idade = int(input("Sua idade? "))   # converte texto em número

print(f"Olá, {nome}! Você tem {idade} anos.")

4.2 A explicação

input() lê o que o usuário digita (sempre como texto), e int() converte esse texto em número. As f-strings (começam com f) permitem inserir variáveis dentro do texto, junto das chaves {} — o jeito moderno e limpo de formatar.

Experimente

Modifique o código para calcular a idade no próximo ano: print(f"Ano que vem: {idade + 1}").

Desafio — seu primeiro mini-programa

Agora é a sua vez. Monte um programa que:

  • peça o nome e a altura de uma pessoa;
  • mostre uma frase como: "Ludimila tem 1.52 m de altura.";
  • diga se a altura é maior que 1.70 (usando if e comparação).
PYTHON — solução do desafio
nome = input("Nome: ")
altura = float(input("Altura (em metros): "))

print(f"{nome} tem {altura} m de altura.")

if altura > 1.70:
    print("Acima da média.")
else:
    print("Na média ou abaixo.")

Checklist

  • Criei e usei uma variável
  • Sei a diferença entre int, float, str e bool
  • Usei operadores de comparação e lógicos
  • Li um dado com input()
  • Formatei uma frase com f-string
