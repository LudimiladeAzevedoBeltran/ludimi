Seção 1 — DataFrame e Series

1.1 O código

PYTHON — criando um DataFrame
import pandas as pd

dados = {
    "pais": ["Brasil", "Brasil", "Colômbia"],
    "media": [85.2, 90.1, 78.4],
    "tipo_cafe": ["arábica", "arábica", "robusta"],
}

df = pd.DataFrame(dados)
print(df)

1.2 A explicação

Dois conceitos fundamentais:

  • DataFrame — uma "tabela" com linhas e colunas (o prato principal).
  • Series — uma coluna (um vetor de valores).

Você cria um DataFrame a partir de um dicionário (chave = nome da coluna, valor = os dados). A partir daqui, tudo fica fácil de manipular.

Seção 2 — Lendo dados de arquivos

2.1 O código

PYTHON — lendo CSV e Excel
import pandas as pd

csv = pd.read_csv("dados_cafe.csv")
excel = pd.read_excel("dados_cafe.xlsx")

print(csv.head())     # primeiras linhas
print(excel.shape)    # (linhas, colunas)

2.2 A explicação

read_csv(), read_excel() e read_parquet() carregam os dados. O pandas entende o formato e monta o DataFrame para você. Isso é o que conecta seu trabalho com as planilhas, bancos e arquivos da pesquisa.

Métodos úteis
  • head(n) — primeiras n linhas.
  • shape — dimensões (linhas, colunas).
  • info() — tipos e valores ausentes.
  • columns — os nomes das colunas.

Seção 3 — Explorando e filtrando

3.1 O código

PYTHON — describe e filtros
import pandas as pd

df = pd.read_excel("dados_cafe.xlsx")

print(df.describe())                 # resumo estatístico

# selecionar uma coluna
medias = df["media"]

# filtrar: países com média acima de 80
altos = df[df["media"] > 80]
print(altos)

3.2 A explicação

O que faz cada parte

df.describe() traz contagem, média, desvio, mínimo e máximo de cada coluna numérica — sua primeira olhada nos dados. O filtro df[condição] seleciona as linhas em que a condição é verdadeira. É aqui que você começa a "perguntar" coisas aos dados.

Valores ausentes

Dados reais quase sempre têm lacunas (NaN). Use df.isna().sum() para ver onde estão e df.dropna() ou df.fillna(valor) para tratar — decisão que impacta toda a análise.

Seção 4 — Agrupando com groupby

4.1 O código

PYTHON — groupby
import pandas as pd

df = pd.read_excel("dados_cafe.xlsx")

# média por país
media_pais = df.groupby("pais")["media"].mean()
print(media_pais)

# média por país E tipo
media_dois = df.groupby(["pais", "tipo_cafe"])["media"].mean()
print(media_dois)

4.2 A explicação

groupby() agrupa as linhas por uma categoria e depois aplica uma agregação (mean, sum, count). É o comando que responde perguntas como: "qual a média por país?", "qual a média por país e tipo de café?", "quantas amostras por região?".

Poder de verdade

Com groupby, em uma linha você resume uma tabela inteira. Depois, com describe() dentro do grupo, obtém um resumo completo por categoria. É a base de quase toda análise exploratória.

Desafio — análise de um conjunto real

Você tem os dados de notas dos alunos. Calcule a média por aluno e a média geral da turma.

PYTHON — solução com pandas
import pandas as pd

df = pd.read_csv("notas.csv")   # colunas: aluno, nota

media_aluno = df.groupby("aluno")["nota"].mean()
print(media_aluno)

print("Média geral:", df["nota"].mean())
