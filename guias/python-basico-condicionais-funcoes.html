Seção 1 — Condicionais

1.1 O código

PYTHON — if / else
nota = 7.5

if nota >= 7:
    print("Aprovado")
else:
    print("Reprovado")

1.2 A explicação

O comando if executa um bloco apenas se a condição for verdadeira. O else executa quando ela é falsa. Repare no dois-pontos (:) e na indentação (o recuo) — no Python, o recuo define o que está dentro de cada bloco.

Atenção à indentação

Você pode usar 4 espaços (padrão). Misturar espaços e tab causa erro. Se o bloco não estiver indentado, o if "não enxerga" o que vem depois e o programa quebra.

Seção 2 — Encadeando com elif

2.1 O código

PYTHON — if / elif / else
temp = 32

if temp >= 35:
    print("Muito quente")
elif temp >= 28:
    print("Quente")
elif temp >= 20:
    print("Ameno")
else:
    print("Frio")

2.2 A explicação

elif ("else if") serve para testar condições em sequência, na ordem, e parar na primeira verdadeira. Aqui é útil para classificar faixas — como temperatura, concentração, ou qualquer variável contínua da sua pesquisa.

Aplicação na ciência

Essa lógica é usada para classificar dados: "peso abaixo/ideal/acima", "índice de vegetação baixo/médio/ alto", "risco de queimada". Perceba que ordem das condições importa.

Seção 3 — Funções

3.1 O código

PYTHON — definindo uma função
def saudar(nome):
    print(f"Olá, {nome}!")

saudar("Ludimila")   # Olá, Ludimila!
saudar("Ana")       # Olá, Ana!

3.2 A explicação

Uma função é um bloco de código com nome, que você pode chamar quantas vezes quiser. Defina com def, seguido do nome, parênteses e dois-pontos. O parâmetro nome é o "entrada". Isso evita repetir código — se precisar mudar a mensagem, muda em um único lugar.

Vantagem

Imagine calcular a média de 10 conjuntos de dados. Sem função, você copia o cálculo 10 vezes. Com uma função, escreve uma vez e chama para cada conjunto. É a base de um código limpo (e é assim que as bibliotecas funcionam).

Seção 4 — Argumentos e Retorno

4.1 O código

PYTHON — função que retorna valor
def media(notas):
    soma = sum(notas)
    n = len(notas)
    return soma / n

notas_turma = [8.5, 9.0, 7.5, 6.0]
resultado = media(notas_turma)
print(resultado)          # 7.75

4.2 A explicação

return devolve o resultado para quem chamou a função. Diferente do print (que só mostra na tela), o return entrega um valor que você pode guardar em uma variável e usar depois. Isso é o que permite compor funções maiores.

print × return

print exibe e pronto. return devolve o valor para o programa continuar — por isso é o que usamos quando queremos usar o resultado em outro cálculo.

Desafio — função que classifica

Combine função + condição. Crie uma função classificar_umidade que recebe um valor e retorna o texto "Seco", "Úmido" ou "Muito úmido" (use if/elif dentro da função).

PYTHON — solução
def classificar_umidade(valor):
    if valor < 30:
        return "Seco"
    elif valor < 70:
        return "Úmido"
    else:
        return "Muito úmido"

print(classificar_umidade(20))   # Seco
print(classificar_umidade(50))   # Úmido
print(classificar_umidade(85))   # Muito úmido
