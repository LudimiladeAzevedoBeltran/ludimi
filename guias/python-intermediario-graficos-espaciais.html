Sobre este guia

Quando seus dados têm localização, você precisa de ferramentas especiais. O geopandas estende o pandas para lidar com geometrias (pontos, linhas, polígonos). Neste guia, todas as geometrias são criadas no próprio código — assim você pratica de imediato, sem precisar de arquivos externos.

Seção 1 — Geometrias com shapely

PYTHON — criando geometrias
from shapely.geometry import Point, LineString, Polygon

ponto = Point(-48.5, -15.8)      # longitude, latitude
linha = LineString([(-48.5, -15.8), (-47.5, -15.8)])
poligono = Polygon([(-49, -16), (-48, -16), (-48, -15), (-49, -15)])

print(ponto)
print(linha)
print(poligono)
Os três tipos de geometria
  • Point — um ponto (ex.: uma amostra, uma estação).
  • LineString — uma linha (ex.: uma estrada, um rio).
  • Polygon — um polígono (ex.: um município, um bioma).

Seção 2 — O GeoDataFrame

PYTHON — criando um GeoDataFrame
import geopandas as gpd
from shapely.geometry import Point

gdf = gpd.GeoDataFrame(
    {"nome": ["Estação A", "Estação B", "Estação C"],
     "temperatura": [28.5, 30.1, 26.9]},
    geometry=[Point(-48.5, -15.8), Point(-48.2, -16.1), Point(-47.9, -15.7)],
)

print(gdf.head())
print(gdf.geometry)     # a coluna de geometrias
Diferença para o pandas

Um GeoDataFrame é um DataFrame com uma coluna especial geometry. É isso que permite desenhar no mapa e fazer consultas espaciais. Todo o resto funciona igual ao pandas (groupby, describe, filtros).

3.2 Mapa temático (coroplético)

PYTHON — colorindo por valor
# um pequeno conjunto de polígonos com um valor
poligonos = gpd.GeoDataFrame(
    {"regiao": ["A", "B", "C"],
     "indice": [12, 45, 30]},
    geometry=[
        Polygon([(-49,-16),(-48,-16),(-48,-15),(-49,-15)]),
        Polygon([(-48,-16),(-47,-16),(-47,-15),(-48,-15)]),
        Polygon([(-49,-15),(-48,-15),(-48,-14),(-49,-14)]),
    ],
)

poligonos.plot(column="indice", cmap="YlOrRd", legend=True)
plt.title("Índice por região")
plt.show()
Parâmetros do plot
  • column — a coluna usada para colorir.
  • cmap — a paleta de cores (ex.: YlOrRd, Greens).
  • legend=True — mostra a legenda de valores.

Seção 4 — Consultas espaciais

4.1 O que está dentro de uma área

PYTHON — within
from shapely.geometry import Point, Polygon

area = Polygon([(-49, -16), (-48, -16), (-48, -15), (-49, -15)])

pontos = gpd.GeoDataFrame(
    {"nome": ["A", "B", "C"]},
    geometry=[Point(-48.5, -15.5), Point(-48.8, -15.9), Point(-47.6, -15.3)],
)

dentro = pontos[pontos.geometry.within(area)]
print(dentro)

4.2 Distância e interseção

PYTHON — distance e intersects
# distância entre pontos
print(pontos.geometry.distance(area.centroid))

# quais pontos intersectam a área
print(pontos[pontos.geometry.intersects(area)])

O caminho da análise espacial: das formas geométricas à consulta sobre o que está dentro ou perto.
PYTHON — mapa temático completo
import geopandas as gpd
import matplotlib.pyplot as plt
from shapely.geometry import Polygon

regioes = gpd.GeoDataFrame(
    {"nome": ["Norte", "Sul", "Leste"],
     "umidade": [70, 45, 58]},
    geometry=[
        Polygon([(0,2),(2,2),(2,4),(0,4)]),
        Polygon([(0,0),(2,0),(2,2),(0,2)]),
        Polygon([(2,0),(4,0),(4,2),(2,2)]),
    ],
)

fig, ax = plt.subplots(figsize=(7, 5))
regioes.plot(column="umidade", cmap="Greens", legend=True, ax=ax)
ax.set_title("Umidade por região")
ax.set_axis_off()          # tira os eixos
plt.show()
ax.set_axis_off() remove os eixos, deixando o mapa limpo — um toque profissional. Depois é só salvar com plt.savefig("mapa.png", dpi=300).
